# 🖥️ Sistema de Gestión de Incidencias Tecnológicas

Sistema web desarrollado para el control, registro y seguimiento de incidencias en laboratorios de cómputo, diseñado con una interfaz moderna y estética en tonos rosa palo con efectos visuales neón.

## 🚀 Tecnologías Utilizadas
* **Backend:** PHP (con extensiones MySQLi para consultas preparadas).
* **Base de Datos:** MySQL (Gestión mediante phpMyAdmin).
* **Frontend:** Bootstrap 5, HTML5, CSS3 y JavaScript.
* **Tipografía e Iconos:** Google Fonts (Poppins) y FontAwesome 6.
* **Entorno de Ejecución:** XAMPP (Apache / PHP 8.x).

---

## ✨ Características Principales
* **Módulo de Registro:** Permite registrar nuevas incidencias detallando el solicitante, laboratorio, equipo afectado, prioridad y descripción.
* **Filtros Avanzados:** Búsqueda y filtrado dinámico por laboratorio, estado (Pendiente, En proceso, Resuelta) y nivel de prioridad.
* **Acceso Administrativo (Login):** Panel protegido por sesiones para administradores con permisos de edición y eliminación de registros.
* **Diseño UI/UX Personalizado:** Tema visual "Dusty Pink" con tarjetas translúcidas, tipografía moderna y botones con efectos luminosos neón.
